# Nur.Prof.AI — ИИ-профориентация для школьников (демо)

Демо-версия веб-сайта профориентации на основе теста Климова, теста RIASEC и подбора профессий/университетов Казахстана.

## Возможности

- 📋 Анкета (возраст, страна, целевая страна, текущие баллы ЕНТ/IELTS/SAT)
- 🧭 Тест Климова (10 ситуативных вопросов, 5 вариантов ответа)
- 🎯 Тест RIASEC (10 вопросов)
- ❤️ Выбор интересов и привычек (где проводишь время, сколько готов заниматься)
- 🤖 Подбор профессий на основе результатов
- 🕹️ «Проба профессии» — мини-задания с рандомизированными вопросами и вариантами
- 🎓 Список университетов (Казахстан + мир) со ссылками на официальные сайты, баллами и ценами
- 📅 Персональный план подготовки
- 🌐 Три языка интерфейса: русский / английский / қазақша

## Технологии

Один файл на чистом HTML/CSS/JavaScript, без сборки и зависимостей (кроме Google Fonts). Открывается прямо в браузере.

## Как запустить локально

Просто откройте `index.html` в любом браузере — сервер не нужен.

## Как открыть онлайн (GitHub Pages)

1. Settings → Pages → Source: **Deploy from a branch**, branch **main**, папка **/(root)**.
2. Через минуту сайт будет доступен по адресу вида:
   `https://<ваш-логин>.github.io/<название-репозитория>/`

## Статус

Учебное демо: логика подбора профессий и вузов упрощённая, работает полностью в браузере без внешнего ИИ-сервиса. Баллы для поступления и цены — примерные ориентиры, не официальные данные вузов.
